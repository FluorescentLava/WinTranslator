# Application icon

The WinTranslater icon is an original generated translation mark using two overlapping rounded panels. The `A` glyph is passion-fruit yellow and the `文` glyph is deep purple, with matched optical size; coral forms the transition between the yellow and purple palette. It is not a Microsoft application logo.

Design reference: Jon Friedman, Microsoft Design, [Fluid forms, vibrant colors](https://microsoft.design/articles/fluid-forms-vibrant-colors/), 1 October 2025. The relevant design principles are simpler silhouettes, soft folds and curves, richer analogous gradients, clear layering, and legibility at small sizes.

Generated with the user-supplied image service using its `gpt-image-2` model. The final transparent PNG preserves the generated alpha channel. The multi-resolution ICO is derived from the same image for Explorer, the tray, and window icons.

The small language-swap path is drawn locally: two parallel thin arrows, each with one outer barb, matching the supplied interface reference. It is separate from the application icon.
