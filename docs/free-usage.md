# 免费额度与在线请求

本程序根据本地账本控制免费在线请求。账本不与服务账户同步，所列上限是程序采用的额度策略，账户实际权益、计费规则与结算周期以服务方为准。

## 服务与计划

- 百度翻译标准版按每月 50,000 字符控制。超出免费额度可能产生费用，使用前需确认账户的计费设置。
- DeepL Developer 按总量 1,000,000 字符控制；DeepL API Free 旧版按每月 500,000 字符控制。两种计划均使用 `api-free.deepl.com`，各自的用量独立保存。设置中的“用量明细”可同时查看两种计划的本地记录。付费计划不加入自动路由。
- MyMemory 无需密钥，匿名请求按每天 5,000 字符控制。
- 腾讯与有道须同时具有 API 凭据和已核实、未到期的免费资源或试用权益。程序不预设每月赠送额度，也不把现金余额或体验金金额换算为免费字符数。缺少有效免费权益时跳过该服务。

## 配置腾讯或有道免费权益

先在设置窗口填写对应服务的 API 凭据，并在服务方账户中确认免费字符数、权益标识和到期时间。随后退出程序，编辑 `%LOCALAPPDATA%\TranslationTool\settings.json` 中的 `tencent_free_grant` 或 `youdao_free_grant`。两项默认均为 `null`；对象结构相同：

```json
{
  "tencent_free_grant": {
    "grant_id": "",
    "quota_characters": 0,
    "expires_at": ""
  },
  "youdao_free_grant": null
}
```

上例中的空值和 0 表示停用。启用时各字段含义如下：

| 字段 | 含义 |
| --- | --- |
| `grant_id` | 免费资源包或试用权益的稳定、唯一编号 |
| `quota_characters` | 已核实可供本程序使用的免费字符总上限，必须大于 0 |
| `expires_at` | 含时区的 RFC 3339 绝对到期时间，例如 `2026-12-08T23:59:59+08:00`，此值仅示范格式 |

保留文件中的其他设置字段，API 密钥通过设置窗口填写。仅能确认赠送金额、无法确认免费字数时，保持对应项为 `null`。

同一权益编号的请求预留永久累计，不随重启、月份或修改上限与到期时间清零。首次使用后，编号绑定对应的 API 标识：修改密钥保留用量，换成其他 API 标识会跳过该权益。只有服务方发放了独立的新权益，才使用新编号。

每次预留及每段请求前均检查有效期。收到服务方额度耗尽错误后，该权益编号不会自动恢复。显示的试用余量包含失败请求的保守预留。

## 路由与等待时间

在线路由先尝试当前所选的可用免费服务，再依次尝试尚未使用的百度、DeepL、腾讯、有道、MyMemory。额度不足、限流、网络或鉴权失败时继续尝试其他服务。启用“自动离线”后，在线候选全部失败或等待预算耗尽会使用本地模型；关闭时显示错误。

短文本整轮在线等待预算为 6 秒，随分段数量增加，最多 30 秒；单次请求最多 3 秒。MyMemory 每段不超过 450 个 UTF-8 字节；百度每段不超过 1,000 字符，且每秒最多一次请求。输入变化可取消后续请求。

超过 5,000 个 Unicode 字符的文本自动使用本地模型翻译全文。手动选择在线服务时，只发送前 5,000 个字符；此限制与各服务的分段和额度限制同时适用。

## 用量账本与结果缓存

免费字符数在请求发出前持久预留，避免并发或重启重复使用本地记录的额度。失败或取消的请求仍保守计入用量。额度、限流和临时错误分别经过相应冷却后再尝试。

自动切换在线服务或转为本地模型的结果不进入翻译会话缓存，后续请求可重新尝试恢复可用的首选服务。用量明细只展示账本，查看时不修改计划或记录。

账本无法获知其他客户端的请求，显示有余量也不保证账户仍有免费权益。服务方规则发生变化时，仍需以账户实际权益为准。
